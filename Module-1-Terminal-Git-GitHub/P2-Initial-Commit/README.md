
# P2: Portfolio Repository with an Initial Commit

## Aim
To initialize a Git repository and create an initial commit.

## Commands and Implementation

### 1. Navigate to Project Folder
```bash
cd MyPortfolio
```

### 2. Initialize Git Repository
```bash
git init
```

### 3. Create README File
```bash
echo "# My Portfolio" > README.md
```

### 4. Check Repository Status
```bash
git status
```

### 5. Add Files to Staging Area
```bash
git add .
```

### 6. Create Initial Commit
```bash
git commit -m "Initial commit"
```

### 7. Rename Branch to Main
```bash
git branch -M main
```

### 8. View Commit History
```bash
git log --oneline
```

## Expected Output
A Git repository initialized successfully with an initial commit on the main branch.

## Result
Successfully initialized a Git repository and created the first commit.
