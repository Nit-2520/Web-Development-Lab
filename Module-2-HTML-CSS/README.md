# Module 2: HTML & CSS Foundations

## Overview
This module focuses on learning the fundamentals of HTML and CSS to create structured, styled, and responsive webpages.

## Objectives
- Understand HTML document structure.
- Use semantic HTML elements.
- Create structured portfolio webpages.
- Understand CSS design tokens and typography.
- Apply CSS positioning properties.
- Build responsive layouts using Flexbox.
- Design user-friendly webpages.

## Practicals

| Practical | Title | Description |
|---|---|---|
| P5 | Semantic Bio Page | Creating a personal bio webpage using semantic HTML elements. |
| P6 | Full Portfolio Page Structure | Building a complete portfolio structure using HTML. |
| P7 | Design Tokens and Typography System | Creating reusable design tokens and typography styles using CSS. |
| P8 | Sticky Navbar and Card Overlay | Using CSS positioning to create a sticky navbar and card overlays. |
| P9 | Responsive Navbar and Card Grid | Creating responsive navigation and card layouts using Flexbox. |

## Tools and Technologies Used
- HTML5
- CSS3
- GitHub

## Learning Outcomes
After completing this module, I understand semantic HTML, webpage structure, CSS styling, design tokens, positioning, and responsive layouts using Flexbox.
