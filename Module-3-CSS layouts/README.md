# Module 3: CSS Layout Systems

## Overview
This module focuses on advanced CSS layout techniques using Flexbox and CSS Grid to create structured, responsive and visually appealing webpages.

## Objectives
- Understand advanced CSS Flexbox properties.
- Create responsive portfolio headers and footers.
- Understand CSS Grid layouts.
- Design multi-column newspaper layouts.
- Create advanced portfolio project grids.
- Compare Flexbox and CSS Grid.
- Choose appropriate layout systems for different webpage requirements.

## Practicals

| Practical | Title | Description |
|---|---|---|
| P10 | Portfolio Header and Footer with Advanced Flexbox | Creating a portfolio header and footer using advanced Flexbox properties. |
| P11 | Newspaper-Style Three-Column Layout | Creating a newspaper webpage using CSS Grid. |
| P12 | Portfolio Projects Grid with Advanced CSS Grid | Designing a portfolio projects section using advanced Grid properties. |
| P13 | Choosing Between Flexbox and Grid | Comparing and implementing Flexbox and Grid for shared layouts. |

## Tools and Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- GitHub

## Learning Outcomes
After completing this module, I understand advanced Flexbox and Grid layouts, responsive webpage design, multi-column arrangements and the differences between CSS Flexbox and Grid.

## Conclusion
This module helped me understand how to build modern, responsive and well-organized webpage layouts using CSS Flexbox and CSS Grid.
