# Module 1: Terminal, Git & GitHub

## Overview
This module covers the fundamentals of using the terminal, managing project folders, and working with Git and GitHub for version control.

## Objectives
- Understand basic terminal commands.
- Create and manage project folders.
- Initialize and manage Git repositories.
- Understand commits and branches.
- Upload projects to GitHub.
- Create README files and version tags.

## Practicals

| Practical | Title | Description |
|---|---|---|
| P1 | Project Folder and Terminal Navigation | Creating folders and navigating using terminal commands. |
| P2 | Portfolio Repository with Initial Commit | Initializing a Git repository and making the first commit. |
| P3 | Feature-Branch Git Workflow | Creating branches and merging changes. |
| P4 | GitHub README and Version Tags | Creating a README, connecting GitHub and managing version tags. |

## Tools Used
- Terminal
- Git
- GitHub

## Learning Outcomes
After completing this module, I understand basic terminal navigation, Git version control, repository management, branching, commits, and GitHub collaboration workflows.
