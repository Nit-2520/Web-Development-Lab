# Web Development Practicals

Welcome to my Web Development Practicals repository! This repository contains my practical work covering web development fundamentals, HTML, CSS, Flexbox and CSS Grid, organized into three modules.

## About This Repository

The purpose of this repository is to document my learning journey in web development through practical implementation and hands-on exercises.

## Modules

### Module 1: Terminal, Git & GitHub

**Practicals: P1–P4**

Topics covered:
- Project folder creation and terminal navigation
- Portfolio repository with an initial commit
- Feature-branch Git workflow
- GitHub README and version tags

### Module 2: HTML & CSS Foundations

**Practicals: P5–P9**

Topics covered:
- Semantic bio webpage
- Full portfolio page structure
- Design tokens and typography system
- Sticky navbar and card overlay
- Responsive navbar and card grid using Flexbox

### Module 3: CSS Layout Systems

**Practicals: P10–P13**

Topics covered:
- Portfolio header and footer with advanced Flexbox
- Newspaper-style three-column layout using CSS Grid
- Portfolio projects grid with advanced CSS Grid
- Choosing between Flexbox and Grid for a shared layout

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Git
- GitHub
